# Изображения

Поместите сюда все изображения для сайта:

## Логотип:

1. **logo.png** или **logo.jpg** или **logo.svg** - Логотип компании Lora Gate
   - Используется в: `src/app/components/Header.tsx` и `src/app/components/Footer.tsx`
   - Рекомендуемый размер: минимум 160x160px (для отображения 40x40px)
   - Формат: PNG с прозрачным фоном (рекомендуется) или SVG

## Изображения оборудования:

1. **gateway.jpg** или **gateway.png** - Фотография шлюза RD07 Wi-Fi
   - Используется в: `src/app/components/Equipment.tsx`
   - Рекомендуемый размер: минимум 800x600px

2. **sensor.jpg** или **sensor.png** - Фотография датчиков TAG 08 / TAG 08B
   - Используется в: `src/app/components/Equipment.tsx`
   - Рекомендуемый размер: минимум 800x600px

3. **hero-warehouse.jpg** или **hero-warehouse.png** - Фотография системы мониторинга на складе
   - Используется в: `src/app/components/Hero.tsx`
   - Рекомендуемый размер: минимум 1200x800px

4. **dashboard.jpg** или **dashboard.png** - Скриншот веб-приложения/дашборда
   - Используется в: `src/app/components/WebApp.tsx`
   - Рекомендуемый размер: минимум 1200x800px

5. **case-pharma.jpg** или **case-pharma.png** (опционально) - Фото фармацевтического склада
   - Используется в: `src/app/components/Cases.tsx`
   - Рекомендуемый размер: минимум 1000x600px

6. **case-food.jpg** или **case-food.png** (опционально) - Фото пищевого склада
   - Используется в: `src/app/components/Cases.tsx`
   - Рекомендуемый размер: минимум 1000x600px

## Форматы файлов:
- Поддерживаются: JPG, JPEG, PNG, WebP
- Рекомендуется использовать WebP для лучшей оптимизации

## После добавления изображений:
1. Убедитесь, что файлы имеют правильные имена
2. Запустите `npm run build` для пересборки проекта
3. Проверьте, что изображения отображаются корректно
