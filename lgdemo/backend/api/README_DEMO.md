# Демо-версия API

Эта папка содержит демо-версии API endpoints, которые работают **без базы данных**.

## 📁 Структура файлов

### Демо-версии API:
- `auth/demo-login.php` - Авторизация (логин: demo, пароль: demo123)
- `sensors/demo-current.php` - Текущие данные датчиков (6 датчиков)
- `sensors/demo-history.php` - История датчиков
- `groups/demo-index.php` - Список групп (1 группа)
- `groups/demo-sensors.php` - Датчики группы
- `users/demo-current.php` - Текущий пользователь
- `alerts/demo-index.php` - Алерты (пустой список)

### Конфигурация:
- `config/demo-mode.php` - Конфигурация демо-режима
- `.htaccess-demo` - Правила Apache для автоматического переключения
- `demo-router.php` - Роутер для перенаправления запросов

## 🔧 Использование

### Вариант 1: Автоматическое переключение (Apache)

1. Скопируйте `.htaccess-demo` в `.htaccess`:
   ```bash
   cp .htaccess-demo .htaccess
   ```

2. Готово! API автоматически будет использовать демо-версии.

### Вариант 2: Ручное переключение

Переименуйте демо-файлы, заменив оригинальные:
- `auth/demo-login.php` → `auth/login.php`
- `sensors/demo-current.php` → `sensors/current.php`
- и т.д.

## ⚠️ Важно

- Демо-режим работает **без базы данных**
- Все данные статичны
- Изменения не сохраняются
- Для production используйте обычные API endpoints с базой данных
