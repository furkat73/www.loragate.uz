# Заполнение базы данных тестовыми данными

Если вы видите уведомление "База данных пустая" в панели управления, это означает, что таблица `sensor_data` в базе данных `lora_gate` не содержит данных.

## Способы заполнения базы данных

### Способ 1: PHP-скрипт (Рекомендуется)

Используйте скрипт `fill-sensor-data.php`, который автоматически заполнит таблицу тестовыми данными.

#### Шаги:

1. **Настройте параметры подключения к базе данных**
   
   Откройте файл `backend/api/fill-sensor-data.php` и измените следующие строки:
   ```php
   $db_host = 'localhost';
   $db_name = 'lora_gate';
   $db_user = 'root'; // ИЗМЕНИТЕ на ваше имя пользователя
   $db_pass = ''; // ИЗМЕНИТЕ на ваш пароль
   ```

2. **Запустите скрипт**
   
   - **Через браузер**: Откройте `http://ваш-домен/api/fill-sensor-data.php`
   - **Через командную строку**: `php backend/api/fill-sensor-data.php`

3. **Проверьте результат**
   
   Скрипт вернет JSON-ответ с информацией о количестве добавленных записей.

#### Что делает скрипт:

- Проверяет существование таблицы `sensor_data` (создает, если её нет)
- Проверяет, есть ли уже данные в таблице (пропускает заполнение, если данные есть)
- Генерирует тестовые данные для 6 устройств за последние 7 дней
- Добавляет по одной записи каждый час для каждого устройства (всего ~1008 записей)

### Способ 2: SQL-скрипт (Вручную)

Используйте SQL-скрипт `fill-sensor-data.sql` для ручного добавления данных через phpMyAdmin или MySQL CLI.

#### Шаги:

1. Откройте phpMyAdmin или подключитесь к MySQL через командную строку
2. Выберите базу данных `lora_gate`
3. Импортируйте файл `backend/api/fill-sensor-data.sql` или скопируйте и выполните SQL-команды

**Примечание**: SQL-скрипт добавляет только несколько примеров записей. Для полного заполнения используйте PHP-скрипт.

### Способ 3: Через phpMyAdmin (Ручной)

1. Откройте phpMyAdmin
2. Выберите базу данных `lora_gate`
3. Откройте таблицу `sensor_data`
4. Нажмите "Вставить" и добавьте данные вручную

## Структура таблицы sensor_data

Таблица должна содержать следующие поля:

- `id` - автоинкрементный идентификатор
- `device_id` - ID устройства (например, 'TAG-08B-82257480')
- `sensor_id` - ID сенсора
- `temperature` - Температура (decimal)
- `humidity` - Влажность (decimal)
- `battery_level` - Уровень батареи (int, 0-100)
- `battery_voltage` - Напряжение батареи (decimal)
- `signal_strength` - Сила сигнала (int, в dBm)
- `timestamp` - Временная метка записи (datetime)
- `created_at` - Время создания записи (datetime)

## Проверка после заполнения

После заполнения базы данных:

1. Обновите страницу панели управления
2. Уведомление "База данных пустая" должно исчезнуть
3. На графиках и диаграммах должны отобразиться данные

## Устранение проблем

### Ошибка подключения к базе данных

Проверьте:
- Правильность имени хоста, имени базы данных, имени пользователя и пароля
- Доступность сервера MySQL
- Права пользователя на базу данных `lora_gate`

### Таблица не существует

Скрипт `fill-sensor-data.php` автоматически создаст таблицу, если её нет. Если вы используете SQL-скрипт, убедитесь, что выполнили команду `CREATE TABLE` перед вставкой данных.

### Ошибка "Access denied"

Убедитесь, что пользователь базы данных имеет права на:
- CREATE TABLE (если таблица не существует)
- INSERT (для добавления данных)
- SELECT (для проверки существующих данных)

## Контакты

Если возникли проблемы, проверьте:
1. Логи ошибок PHP
2. Логи MySQL
3. Права доступа к файлам и базе данных
